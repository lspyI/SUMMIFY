# SUMMIFY — Интеллектуальный ИИ-конспектор лекций

**SUMMIFY** — это высокотехнологичное Android-приложение для студентов и профессионалов, которое превращает живую речь в структурированные, чистые заметки в реальном времени. Приложение написано на **Kotlin** с использованием **Jetpack Compose** и сочетает в себе эстетику Cyberpunk с мощью нейросетей.

### Основные функции и технологии:
*   **ИИ-Стенографист (Gemini 3.6 Flash)**: Мгновенная обработка транскрипции лекции. ИИ убирает лишний шум, исправляет ошибки распознавания и структурирует текст.
*   **Фоновая запись (Foreground Service)**: Приложение не прерывает работу, даже если вы свернули его или выключили экран. Вы всегда контролируете процесс через уведомление в шторке.
*   **Audio & Text Sync**: Параллельно с генерацией текста SUMMIFY записывает реальное аудио. Вы можете прослушать любой фрагмент лекции прямо из истории.
*   **Eclipse Grid UI**: Уникальный дизайн с анимированной сеткой на фоне, пульсирующими глоу-эффектами и элементами Glassmorphism.
*   **Умная организация**: Система папок для разных предметов, глобальный поиск по содержимому всех конспектов и расшифровок.
*   **Инструменты обучения**: Генерация проверочных квизов (Flashcards) по материалу лекции и экспорт готовых конспектов в PDF.
*   **Визуализация голоса**: Анимированная волна (Waveform) в реальном времени реагирует на громкость речи преподавателя.
*   **Защита данных**: Блокировка случайного выхода во время записи и двойное подтверждение удаления важных папок.

### Технический стек:
`Kotlin`, `Jetpack Compose`, `Material 3`, `Room DB`, `KSP`, `Google Gemini AI (Generative AI SDK)`, `MediaRecorder`, `MediaPlayer`, `Foreground Services`, `PDF Document API`.

### Как запустить проект:
1.  Получите бесплатный API ключ в [Google AI Studio](https://aistudio.google.com/).
2.  Откройте файл `app/src/main/java/com/example/lecturesummarizer/MainActivity.kt`.
3.  Найдите строку `apiKey = "ВАШ_API_КЛЮЧ_ЗДЕСЬ"` и вставьте ваш ключ.
4.  Соберите проект в Android Studio (требуется версия Ladybug или новее, `compileSdk 37`).

Проект построен на архитектуре MVVM и демонстрирует чистый подход к интеграции ИИ и системных сервисов Android. Это идеальный пример современного приложения для портфолио.
